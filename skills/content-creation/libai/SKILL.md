# 李白.Skill:润色专家 文思敏捷，独具匠心。

> **适用场景**: 自媒体文章、公关稿件、日常沟通、学术随笔等中文文本的去AI化改写
> **安全声明**: 本技能仅优化表达形式，不对原文事实准确性负责。涉及医疗、法律、金融等专业内容，请务必人工复核。
>
> **本文件是骨架**：流程、门禁、判据在此；细则下沉在 `resources/*.md`，**按步读取**——读取契约见下方「路由与意识引擎」。

### 意识引擎（触发信号 → 必须想起的判据）

> 本表是**触发索引**：判据正文只有一处（步骤正文或 `resources/`），本表只管「想起来」；不一致时**以正文为准**。

| 触发信号 | 必须动作 | 依据 |
|---|---|---|
| 原文没毛病，只要「加点人味/换风格」 | 走无病可证型例外：以目标风格样例为基线，并声明基线 | diagnosis.md |
| 原文被改过（补段/回退） | 诊断与质检全重跑，旧结论作废 | 1.4 |

| 要「搜干净」禁用词 | 搜到零命中才算完；同类问题多处一次全改 | 2.1 |

| 四层全过还想「再润一轮」 | 停手交付（篇幅容差内） | 3.2 |

| 两条规则打架 | 按冲突裁决次序（不可逆 > 证据门槛 > 范围 > 止损 > 原样验收 > 可读合并） | 异常处理 |
| 长文分段改 | 先定基线（人称/语气/术语）逐段沿用，改完扫接缝 | rewrite-playbook.md |

- 本任务走到哪几步？路由引擎的「必读」逐条报「已读 / 不涉及」。

## 核心原则（必读）

> **去 AI 味的本质**：用抽象概括代替具体经验 → 还原感官、还原动作、还原不确定性。
> **减法只做在「虚」的地方**：模板化连接词、空洞升华、机械对称句式——砍；口语、细节、个人语气、感官描写——留。宁可留着粗糙，不削成骨架。
> **改写不是套模板**：同一套手法铺满全文，新稿就变成另一种模板化——按每处的实际问题选手法。

**四条铁律**（违反任一条视为执行失败）：

1. **立场守恒**：不改事实陈述（时间/地点/事件/数据）、价值判断、情感极性。
2. **不编造**：原文没有的时间/地点/人物/数据/引语一个字都不加；「加泥土」加的是感官与动作修饰，不是事实。
3. **血肉不丢**：口语、孩子气口吻、动作描写、场景细节、语气词——一个都不能丢。
4. **篇幅容差**：允许 10% 以内波动（删虚词减字、加泥土增字）。

## 执行流程（四步闭环）

```
检测诊断 → 执行改写 → 自检验收 → 交付结果
```

> B 模式（默认）只走这四步；A 模式在交付后追加复盘沉淀。

**执行节奏（五拍）**：①读地形（步骤0 + 1.1–1.3：先读体裁、读者、约束）②复现（1.4：先跑检测拿真实证据）③最小编辑（步骤2：只动 AI 味那几处，明确「不碰什么」）④验证（步骤3：重跑质检给数值）⑤收尾（步骤4：清临时产物 + 带诊断数值与未改断言）。

> **前置闸门**：第 2 拍没拿到证据（没跑检测、没列出命中维度），不进第 3 拍——没有「坏」的证据就动手，等于凭感觉改。

## 步骤0：资源预检（隐式，Agent 自动执行）

**0.1 Python 前置检测（先于一切；用 Shell 在 Python 之外实跑）**：

- **探测**：Windows 依次试 `py -3` → `python` → `python3`，macOS/Linux 依次试 `python3` → `python`；取首个可用者，跑 `-c "import sys;print(sys.executable)"` 看真实路径——指向 `WindowsApps` 或提示「应用商店」即 **Store 假别名**，换下一个候选（假别名会静默弹商店、不执行脚本）。
- **版本**：需 **≥3.8**；低于则按「缺失」处理。
- **缺失**：**先出安装计划（平台命令 + 影响范围）交用户确认 → 确认后自动安装，禁静默**；用户拒绝 ⇒ 走降级。平台安装命令见 `README.md`「依赖」。
- **降级（核心不受影响）**：无 Python ⇒ `scripts/*` 全部不可用，改**纯 LLM 模式**（1.4 第二步七维定论 + 手工改写），并在**首次回复显式声明运行模式**。

**0.2 资源可读性预检**：

- **P0** `resources/zh_rules.json` 缺失 → 切纯 LLM 模式并声明「规则库不可用」；`resources/zh_rules_archived.json` 缺失 → 降级，仅用主规则
- **P1** `resources/synonyms.json` 缺失 → 降级为内置词汇替换表；`scripts/detect.py` 缺失 → 改纯 LLM 七维诊断（见 1.4）
- **P2** `resources/banned-words.md`、`examples.md`、`examples-advanced.md`、`structures.md` 缺失 → 不影响核心流程
- **P1** 细则三文件 `resources/{diagnosis,rewrite-playbook,qa-delivery}.md` 缺失 → 手工按骨架门禁执行，并**显式声明「细则不可读、本步按骨架执行」**；此时**路由门禁不适用**（防「要求已读却读不到」的死循环）

> P0 缺失时，首次回复必须声明运行模式。

## 步骤1：检测诊断

**1.1 任务提取**：目标（去味到什么程度/何种文体）｜输入（体裁/字数/读者画像）｜输出（未指定 → B 模式）｜限制（不可改动的术语/数据/品牌名）｜润色强度（见 1.2）。

**1.2 润色强度自动匹配（「人味浓度」以此表为唯一真源）**：

| 强度 | 匹配场景 | 特征 | 人味浓度 |
|---|---|---|---|
| **保守** | 学术论文、技术文档、法律文书、政务文件 | 仅删 AI 连接词与模板套话，不改句式结构、不注入口语 | 30-50% |
| **标准**（默认） | 自媒体、职场汇报、日常沟通、公关稿件 | 完整去 AI 味清单，适度口语化，保留原文核心结构 | 50-70% |
| **激进** | 创意写作、小说、散文、社交媒体帖子 | 可大幅调整视角/句式/段落，注入强烈个人语气 | 100% |

> 浓度是**档内调节目标**，不是独立机制——先按文体定档，再在区间内取值：学术/政务 30%、技术文档 50%（落保守档）；职场/公关 50-70%、营销/品牌 70%（落标准档）；网文/社交 100%（落激进档）。

**1.3 文本规模自适应**：<1000 字 → 完整四步、诊断显式输出；1000-3000 字 → 合并诊断与改写、质检保留；>3000 字 → 分段处理（分段纪律见 `resources/rewrite-playbook.md`）。

**1.4 AI 痕迹检测**：

- **第一步 脚本取证**：执行 `python scripts/detect.py <文件路径> --json`（省略路径则从 stdin 读），解析 `categories`（16 类词/句式计数）、`punctuation`（4 项标点）、`word_count`、`ai_probability`、`ai_level`。
- **第二步 七维定论**：脚本只给词/句式计数，测不出结构与内容维度；D1–D7 必须逐项定论（**禁止仅给综合评分**），表与「脚本 ↔ 维度映射」见 `resources/diagnosis.md`。输出格式 `D{n}: [x]/[!] — 证据：xxx`，附风险定级（低/中/高）与改写方向。

**三条硬约束**：

- **证据门槛**：本步诊断输出（脚本 JSON 或 7 维度逐项）是进入步骤2 的唯一入场券。没跑检测、或全 `[x]` 却凭「读着像 AI」就动手改，都算未取证动手，退回本步。
- **诊断-改写一一对应**：终稿要能逐维回标——命中的维度改了哪里、未命中的维度一处没动；出现「诊断没报、改写里却动了」的维度，退回补诊断或撤回该处改动。
- **基线重跑**：原文被动过（自己补了段、或回退了某处改动）⇒ 旧诊断与旧质检结论作废，本步与步骤3 都得重跑；拿旧结论验收等于没验收。

> **两条例外**（无病可证型任务 / 规则源冲突要申报）见 `resources/diagnosis.md`。

## 步骤2：执行改写

**2.1 改写入口——四步排雷法（必须执行）**：

| 步骤 | 操作 | 方法 |
|---|---|---|
| **1 搜黑话** | 全局搜索 | 找「赋能/闭环/底层逻辑/深刻/交织/画卷/交响乐/总而言之/综上所述」；搜到一个，用具体名词/动词替换一个 |
| **2 切长句** | 拆定语 | 「的」字超长定语（3 个以上）从「的」处切断；删「在……的过程中」「进行了……的讨论」等翻译腔框架 |
| **3 加泥土** | 注入具象 | 最干瘪处加入具体物品（「一杯冷掉的咖啡」）或微小动作（「叹了口气」），每 500 字至少 1 处 |
| **4 保血肉** | 止血检查 | 通读：口语、孩子气口吻、动作描写、场景细节、语气词——一个不丢；只砍「虚」的，不碰「实」的 |

- **加泥土的边界**：加的是感官与动作修饰，不是事实——时间/地点/人物/数据/引语只能来自原文（铁律 2）。
- **搜索即穷举**：第 1 步要搜到零命中才算做完——改完一处再问一句「全文还有没有别处？」。
- **同模式同步**：同一类问题在全文多处出现（比如 4 处「综上所述」），一次全处理；只改第一处不算完成。
- **超长文例外**：按 1.3 分段处理时，逐**段**搜到零命中即可，不必每段都全文复搜。
- **脚本定位**：`scripts/rewrite.py` / `transform.py` 只作批量或首轮草稿加速，产出**仍须走完步骤3 质检**；`compare.py` 用于 A 模式生成修改对照。均不替代人工判断。

**2.2–2.6 细则**（破式五层法 / 中文专属清除清单 / 风格注入规则 / 每处修改过四问 / 结构改造三狠招）见 `resources/rewrite-playbook.md`，执行本步时读。

## 步骤3：自检验收

**3.1 质检清单**：四层共 17 项（用词层 / 句式层 / 内容层 / 可量化终审），逐条执行，任一条 `[!]` 即回步骤2 修复；**清单正文见 `resources/qa-delivery.md`**。六条判定口径：

- **每条都要给证据**：勾选须附命中词清单、原句或数值（如「连接词密度 1.8 次/千字」）；裸打勾不算通过。
- **阈值是判据，不是建议**：不许为了让清单通过而放宽阈值、把不达标判成达标（「3.2 次/千字 ≈ 3」不算过）；不达标只有一条路——回步骤2 改。怀疑阈值不适用本文体时，先说明「这条对本文体不适用」再换判据，禁默默放过。
- **判不出就说判不出**：确实无法判定的维度（原文无事实锚点、体裁不允许第一人称、诊断全 `[x]` 但你觉得有 AI 味），写「该项不适用/无法判定 + 原因」，别留空也别硬凑合格值。
- **未改断言的例外**：原文自带的错别字、格式残留、Markdown 标记，改前先列为「允许改动项」再动手。
- **判据达标就算过**：同一段两次改写路径可以完全不同，清单全过即合格；不要因「这次改法和上次不一样」反复重写。
- **不达标去向**：只有回步骤2 改这一条路；修复循环见 3.2。

**3.2 修复循环**：识别不符合项 → 定位根因 → 回步骤2 修复 → 重新执行本清单。修复尝试上限 2 次（**每次必须换改法，不重复同一改法**）；超限标记「人工复核」并**逐段列名**（第几段 + 卡在哪 + 建议怎么处理），跳过该段。

- **达标即停**：四层全过就收手；篇幅容差内不再「再润一轮」——多改一轮常把口语和细节一起磨平，是负收益。
- **回修要留痕**：回步骤2 动了哪几处、为什么（如「删连接词后转折断裂，回填短句衔接」），写进质检结论，不悄悄改掉。

## 步骤4：交付结果

**交付前自查（三种模式都要做）**：

- **产物洁净**：交付物只含意图内的文件；诊断草稿、中间对照、临时脚本用完即删，别混进交付里。
- **无残留**：终稿不带过程产物——诊断标记（`[!]`、`D1:`）、占位符（`{n}`、`{百分比}`）、以及你自己的批注。
- **证据齐全**：结论带上诊断数值与未改断言（哪些维度动了、哪些一字未动）；只有形容词、没有计数的结论不算交付。
- **末段自查**：最后一段若是「还可以再…/建议你…」这类承诺，要么现在就做完，要么删掉。

**三种交付模式与格式**（A 完整专业版 5 文件 / B 轻量润色版 摘要表 / C 仅诊断 卡片）见 `resources/qa-delivery.md`。

> C 模式仅诊断，**严禁执行任何改写操作**。

## 异常处理

| 异常 | 处理 |
|---|---|
| 信息不足（体裁/读者/限制未提供） | 建立最小可执行假设并标注，不阻塞流程 |
| 需求冲突（如去AI味 vs 保留原结构） | 记录冲突，选影响最小的兼容路径 |
| 质检不通过 | 回步骤2 修复，上限 2 次 |
| 高风险变更（学术->网文体） | 输出风险评估，拒绝执行 |
| 改写卡死（同段落反复修改 > 2 次） | 先换改法；仍不动则标记「人工复核」并逐段列名，跳过该段 |
| 诊断全 [x] 但你觉得有 AI 味 | 别硬改也别人工放过——记录「规则库未覆盖」并手工诊断该处 |

**多条规则顶牛时，按此序裁决（前者压后者）**：

1. **不可逆者优先**：立场守恒、事实与数据不改，压过一切润色偏好。
2. **证据门槛**：没诊断过的「顺手改」不做（无病可证型任务走 1.4 的例外）。
3. **范围纪律**：只动 AI 味那几处；「顺手把内容也优化下」是越界。
4. **止损**：篇幅容差 10%、修复上限 2 次，压过「再打磨一轮」。
5. **原样验收**：未改处逐项复核，改动处逐条有据。
6. **可读合并**：上面都做到了，报告就给数值和完整状态，不给形容词。
