# 改写手册（步骤2 的 2.2–2.6）

> 按需加载：执行步骤2 时读本文件（2.1 四步排雷法在骨架 `SKILL.md`）。本文件是手法与清单，不含规则本身。

## 脚本与本流程的关系

改写以人工判断为准，`SKILL.md` 2.1–2.6 就是 SOP。`scripts/rewrite.py`（8 步流水线）与 `scripts/transform.py` 只作**批量或首轮草稿的加速**，其产出**仍须走完步骤3 质检**；`scripts/compare.py` 用于 A 模式生成修改对照。三者都不替代人工判断。

## 分段不许各自为政

分段改写时先定基线（人称、语气档、术语译法、专名写法），逐段沿用——段间风格漂移（这段口语、那段书面）比 AI 味更出戏。每段改完回头扫一眼相邻段，接不上就返工接缝处。

## 2.2 深度改写——破式五层法（A 模式或高风险时使用）

```
破句式 -> 破词汇 -> 破结构 -> 破思维 -> 破语气
(表层)                                  (深层)
```

| 层级 | 操作 | 手段 |
|---|---|---|
| **L1 破句式** | 打破排比/对仗/工整句式 | 拆长句为短句；删「不仅…而且…」「不是…而是…」对仗框架 |
| **L2 破词汇** | 替换 AI 污染词 | 搜索禁用词（见 `zh_rules_archived.json` 的 `banned_words_v2`，运行时与 `zh_rules.json` 合并加载）；书面词换口语词 |
| **L3 破结构** | 打碎总分总/三段式 | 删小标题；合并 3 段为 1 个长段落；中段插入跑题但微妙的细节 |
| **L4 破思维** | 用「我的片面」替「AI 的全面」 | 删 80% 观点只留最痛一个；加入私人记忆；允许逻辑跳跃 |
| **L5 破语气** | 让「我」的立场和情绪站出来 | 「可能是」->「我赌五毛钱是」；加入小吐槽、怀疑、自嘲 |

> B 模式做到 L2-L3；A 模式推到 L4-L5。
> **看示例只看最小必要**：翻 `resources/examples.md` 时只取**同体裁的 1-2 例**看手法；示例里的题材细节（人名、事件、行业词）是别人的内容，别搬进本稿。

## 2.3 中文专属清除清单

| 问题 | 识别 | 改写 |
|---|---|---|
| "的"字地狱 | 单句"的">=3 个 | 拆分 / 改动词 / 省略冗余修饰 |
| 四字成语堆砌 | 连续>=2 个抽象成语 | 替换为具体数据或白描 |
| 万能连接词 | 段首"首先/其次/最后/综上" | 删除，用话题自然过渡 |
| 伪客观陈述 | "研究表明/专家指出"无出处 | 改"我观察到/说实话"或删 |
| 过度礼貌 | "希望以上内容对您有帮助" | 直接删除 |
| 对称句式 | "不仅…而且…""不是…而是…" | 拆为两个独立短句 |
| 升华结尾 | 以总结/展望/呼吁收尾 | 戛然而止 / 以细节或疑问结束 |

## 2.4 风格注入规则

- **短句占比** >= 全文句数 30%
- **人味锚点**：至少 1 处第一人称视角或主观感受
- **词汇降级**：利用->用、进行购买->买、具备能力->能
- **标点呼吸**：适当使用破折号、省略号、问号制造停顿
- **细节补充**：每 500 字至少 1 处场景/数字/感官锚点

## 2.5 每处修改过四问

1. **删掉影响信息吗？** -> 不影响就删。
2. **能拍成画面吗？** -> 不能就改成能拍的（动作/场景/数据）。
3. **真人会这么说吗？** -> 不会就换成会说的。
4. **原文的「人味」还在吗？** -> 具体细节丢了吗？丢了找回来。

- **改前先推演副作用**：动笔前多问一句「这样改会波及什么」——删掉「然而」后前后句的转折还连得上吗？给长定语瘦身后指代会不会悬空？换了口语词后语气还和人设一致吗？说不清波及面的，先局部试改再铺开。
- **一次只归因一类**：同一轮只动一类问题（比如只去连接词），改完就质检。一趟动七八类，质检不过就分不清是哪一步引进来的。
- **改不动就换改法，别调参**：同一处按一个方向改了两轮还不对，说明方向错了——换层级（L2 词汇换到 L3 结构）或换手法（拆句改合并、删改补），别在同一个词上反复替换同义词。

## 2.6 结构改造三狠招

| 狠招 | 操作 | 效果 |
|---|---|---|
| 删小标题 | 将工整的「一、二、三」删掉 | AI 味消失一大半 |
| 合并段落 | 3 段合并为 1 个长段落，允许转折跑题 | 最反 AI 的结构 |
| 插入跑题 | 中段插入看似不相关但微妙的私人细节 | 人的专属印记 |
