# 微信开发者工具：按需工作流

本模块适配用户提供的 `wechatide-skill 0.3.11`，服务微信小程序/小游戏的开发者工具操作。它是编程大神内的参考模块，不是另一个必须安装的 Skill；不改变主入口的通用编程范围。来源与版本边界见[来源说明](sources.md)。

## 调用与权限

CLI 形式为 `wechatide -c <clientName> <toolName> [flags...]`。`clientName` 是实际宿主产品名，与 IDE 的授权提示一致；同一会话保持一致。工具名用注册表中的原名，参数拼写以本地帮助和注册表核对。需要项目时使用实际绝对路径；复杂 object/array 参数可按该工具帮助使用 JSON 或 `--<field>-file`，不据此杜撰所有参数都支持文件选项。

使用宿主已有的授权连接或可访问本机桌面的执行环境，遵守实际宿主权限。不因上游写“非沙箱”就绕过宿主限制，也不自行扩大网络或文件权限。环境确实无法连接桌面时保存缺口，继续不依赖 IDE 的工作。

主入口的既有授权继续有效，不为已明确要求的普通操作反复聊天确认。上传、分享代码片段、云写入、删除、清理缓存、关闭工具等按具体目标和影响判断；“预览”不自动授权上传或公开分享。`automation_evaluate`、部分页面 action、wx API 和云函数调用可改变状态，不能因为接口名像调试就按只读处理。开发者工具自身的扫码、客户端授权或操作确认仍须真实完成。

CLI 可选访问令牌与 MCP Token 是两类凭据，详见环境页。**不向模型索取、展示或跨会话记忆令牌、ticket、私钥；不把敏感值写入命令文字、项目或报告。** 使用宿主已配置的安全连接，或由本地可信执行程序在进程内读取凭据文件。没有现成安全传递路径时，说明需在客户端本地配置，不能编造本工具支持 `--token-file`。注册表中的 ticket 等字段是协议定义，不是允许把真实值发给模型。

只保留脱敏后的必要错误码、任务状态和业务证据。网络记录、用户信息、云数据或日志可能含敏感值，先按任务缩小范围并在本地脱敏；不要照搬上游“原样抛出错误”的表述转储完整响应。

## 异步任务统一处理

任意工具返回 `status: pending` 和 `taskId`：操作尚未完成。保留原工具、项目、非敏感参数摘要、最后状态和 taskId，提示用户在微信开发者工具内完成对应操作；继续不依赖该结果的工作。

**登录或客户端授权**（`login` / `wechatide auth`）：提示用户扫码/授权后主动查询旧 taskId，每次间隔约 10 秒，单轮最多 10 次。保留进展沟通；最终只有 `success` 才能推进依赖步骤，`failed/cancelled/expired` 不算登录或授权完成。

**其他 pending**（上传、预览确认、删除、云写等）：依来源协议，先提示确认并保留任务，不主动进入固定轮询循环。用户继续或准备再次执行相同操作时先查原 taskId：

```bash
wechatide -c <clientName> polling_task_result --task-id <taskId>
```

| 原任务状态 | 后续动作 |
| --- | --- |
| pending | 不重发原操作；按上述登录/业务规则继续等待或交接 |
| success | 复用原结果，不重复上传、删除或云写 |
| failed | 先看具体错误；仍在原授权范围内且允许安全重试时才重发 |
| cancelled / expired | 用户仍明确要求继续时再发起，不自行恢复已取消操作 |
| 无法查询 / 状态未知 | 不重发可能有副作用的操作，先确认实际状态 |

`pending` 不是失败；CLI 进程正常退出也不等于原任务已成功。状态或网络结果未知时，不能换一个 taskId 重做来制造成功。

## 衔接与交付

跨阶段只带必要上下文：项目路径、AppID、已核实版本关系、登录/窗口状态、当前页或云环境、实际证据及 `pendingTask`。有效状态可复用；IDE 重启、登录失效或版本变化后再核对，不因为换专题重复安装、登录和开窗。

预览推送、二维码生成、手机打开、真实交互、上传、体验版设置、审核和正式发布分别报告。日志/截图/模拟器结果不能替代手机网络、权限和目标流程验证。涉及小游戏时，明确画布坐标与截图尺寸，不能直接套页面选择器。

地图/定位任务可按实际需要使用宿主已有能力、官方资料或相应腾讯地图 Skill；本包未捆绑外部地图 Skill，不强制自动下载。普通业务代码实现仍按编程大神主流程完成。
