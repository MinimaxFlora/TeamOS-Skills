# build() 声明式 UI

`build()` 的 UI 描述区不等于普通函数体。把局部变量声明、日志、请求和状态更新放到成员方法、事件或合适生命周期中；UI 参数中的纯计算可以调用普通方法。

- 页面根节点和自定义组件根节点遵守目标版本的组件约束；`@Entry` 通常需要单一容器根。ForEach/LazyForEach 是渲染控制，不当作有尺寸的实体容器。
- 条件选择组件用 `if/else`。**构造参数或属性值中的三元表达式可以使用**，例如 `Text(this.ready ? '完成' : '处理中')`；不要把“不能用三元替代 UI 组件语句”扩大为任何位置禁用三元。
- 渲染路径不要直接写状态，也不要调用会写状态的方法。`this.items.sort()` 原地改数组；需要排序展示时使用不改变源状态的派生数据。
- `Button('确定')` 与 `Button() { Text('确定') }` 选择一种模式；不要同时给 label 和 children。
- `@Builder` 产出 UI 片段，不返回可链属性的组件对象。需要事件/布局属性时作用在内部组件或外围容器。
- 嵌套循环用 row/cell 等有语义名字便于维护；名字遮蔽是否非法以作用域和编译诊断为准，不把改名当所有嵌套错误的修复。
