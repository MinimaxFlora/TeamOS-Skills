# 样式、主题与动画

- `@Extend` 定义组件样式扩展，`@Styles` 提取通用样式；其参数、导出和放置位置按 UI 编译器规则。不要把普通函数的显式返回类型规则机械套到扩展语法。
- 多态样式使用 `.stateStyles(...)` 属性方法，不存在通用的 `@StateStyles` 装饰器写法。
- stateStyles 支持范围与组件状态有关；普通组件专有属性不能直接当作通用样式属性。
- 深色模式和字体缩放使用资源/主题体系，避免写死颜色与尺寸。自定义节点持有的环境配置要按 API 更新。
- animateTo 的闭包描述可动画状态变化；`.animation()` 放在要影响的属性之后，作用范围按链顺序确认。不能说它必然影响链上的所有属性。
- `curves.*` 是曲线工厂，`Curve.*` 是枚举。springMotion 等不挂在 Curve 上。
- 优先在组件已挂载、状态有效时触发动画；消失动画和节点销毁配合验证。动画结束回调不能承担唯一的数据落盘或业务完成条件。
- 模糊、布局尺寸动画、离屏绘制可能增加开销。选择替代方案要保持视觉和布局语义，并以目标设备证据判断，不强制把所有尺寸动画换成 scale。
- Animator、节点和订阅及时释放；弹簧参数、关键帧支持、onFinish 行为分别查目标 API。
