# 性能与可见性

先找目标设备上的具体开销，再选优化；不根据卡片直接宣称性能提升百分比。

- 不在 build 路径发请求或改状态；缩小状态依赖和重复计算范围。
- 长列表按实际数据量评估 LazyForEach/Repeat 和复用，选择与组件体系及 SDK 匹配的 Reusable API。复用时重置业务状态，验证图片/选中态没有串项。
- 取消已失效的请求、注销订阅、释放动画器和节点；释放动作与资源所有者生命周期一致。
- V1 Track、V2 Trace、冻结和可见区域监听各自有适用范围，不为每个组件一律加装饰器。
- onVisibleAreaChange 反映几何可见区域，不等于用户一定看见内容；遮挡、窗口状态、焦点和渲染状态是不同证据。
- 追踪改动前后同一任务的耗时、卡顿、内存或重渲染次数，避免用构建成功替代性能验证。
