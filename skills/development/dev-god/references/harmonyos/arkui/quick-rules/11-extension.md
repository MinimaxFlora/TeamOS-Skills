# 节点、扩展与交互

- Modifier 是否可复用、是否支持自定义组件、是否能嵌套调用，按实际接口约定；带绑定状态的对象不要未经确认跨多个组件共享。
- FrameNode 区分自定义可修改节点与框架返回的只读代理。修改前确认所有权和生命周期，不对只读系统节点强行设属性或改子树。
- 一个节点只有一个当前父节点；重挂载时先解除旧关系。NodeContainer 接收的节点类型按接口确认。
- AttributeUpdater 与状态属性同时更新同一值会形成多写入者，明确谁拥有状态。
- 事件回调用箭头函数保留期望 this；TouchEvent、ClickEvent、GestureEvent 不能随意互换。
- 手势优先级、并行/互斥组、长按与拖拽需在真实交互中验收；不要仅验证点击就声称拖拽可用。
- 清理拖拽或手势状态要覆盖取消和结束，不能只依赖 onDragLeave 一条路径。
