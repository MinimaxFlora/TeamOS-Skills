# TypeError：值、调用与对象边界

改编自上游同名知识文件；先遵循[证据与来源约定](index.md)。

| 线索 | 候选与确认 | 最小修复 | 复验 |
| --- | --- | --- | --- |
| `Cannot read property` / `null or undefined` | 属性接收者不符合预期；检查接口数据、初始状态、异步回调和销毁后的访问 | 修正值来源/状态时序；合法空值用显式空态，必需数据缺失保留错误 | 初始加载、空响应、快速离开、慢请求 |
| `is not callable` | 值并非函数、导入形式错误、实例不符或回调绑定丢失 | 在失败调用点核对函数值与接收者，修正契约 | 直接调用及回调路径 |
| `Receiver is not a JSObject` | 接收者类型不符；可能涉及 Native 边界，不能仅由字符串断定 | 检查应用/混合栈和边界参数，不盲目强制转换 | 合法对象、错误输入、释放后回调 |
| `Prototype on non ECMA Object` | 对象类型或 N-API handle/env/线程/生命周期问题 | 按实际 Native 调用和 SDK 文档检查 scope、reference 与所属线程 | 异步回调、对象回收、模块卸载路径 |
| `convert ... to a Primitive` | 转换钩子、返回值或实际对象不符合契约 | 查触发转换操作，修正适用的类型/转换逻辑；不要随意加动态方法 | 原运算及边界输入 |
| `circular structure` / `stack contains value` | 序列化对象图可能有环；须确认实际为 stringify/复制路径 | 优先显式构造需要的 DTO；仅在业务允许丢弃引用时采用有说明的去环策略 | 有环、共享但无环、正常数据；检查字段完整性 |

不能将 `WeakSet` 遇到重复对象就丢弃的做法当成通用修复：共享引用不必然是环，丢字段可能破坏业务语义。不要用空 `catch`、遍地可选链或无关强制类型转换掩盖不合法状态。
