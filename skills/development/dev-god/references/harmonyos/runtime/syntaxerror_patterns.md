# SyntaxError：运行时解析

改编自上游同名知识文件；先遵循[证据与来源约定](index.md)。编译器语法报错应走编译错误流程，本页处理日志中的运行时解析失败。

`Unexpected Text in JSON` / `Invalid Token` 可能来自 JSON 解析，也可能来自其他解析器；先用调用栈确认 API 和输入来源。

1. **证据**：检查响应状态、Content-Type、读取/解码方式、长度和脱敏后的局部片段，确认是否收到 HTML 错误页、空值、截断内容或重复解析。不要输出整段业务响应或令牌。
2. **候选**：上游格式错误、读取不完整、编码错误、协议与调用方预期不一致。解析成功也不代表对象字段满足业务契约。
3. **最小修复**：修复生成/获取数据的错误；在解析边界捕获失败并产生明确错误状态，解析成功后再校验结构。不用 `eval`、正则“修补 JSON”或空对象默认值吞掉协议故障。
4. **复验**：合法输入、空响应、非 JSON、截断/非法字符及合法 JSON 但结构不符；确认页面和调用者处理失败的实际行为。
