# 公文写作信息采集模板

复制下列项目并按需填写；不确定的内容可以留空，不要猜测或虚构。

```text
任务类型：从零起草 / 改写 / 润色 / 格式校核 / 降 AI 味
拟用文种：
使用场景与写作目的：
发文主体：
主送对象或目标读者：
行文关系：上行 / 下行 / 平行 / 面向公众 / 不确定
事实与材料要点：
必须保留的数据、名称、政策依据：
责任单位或责任人：
时间节点与反馈方式：
期望篇幅：
格式要求：完整公文要素 / 仅正文 / 考试作答 / 其他
表达要求：正式 / 克制 / 自然 / 降 AI 味 / 其他
禁止出现或不得虚构的内容：
```

信息不足时，优先使用少量 `〔待补充〕` 占位符，并在正文后列出会实质影响交付的缺失项。
